# FB2Kindle

**FB2Kindle** — портативное приложение для Windows 11, предназначенное для конвертации электронных книг из формата **FB2** в **EPUB** для устройств **Amazon Kindle**.

Проект создаётся с нуля и развивается пошагово с использованием Python, PySide6 и GitHub.

---

## Основные возможности

### Уже реализовано

- Выбор нескольких FB2-файлов
- Защита от повторного добавления книг
- Отображение размера файлов
- Удаление выбранных книг
- Журнал работы
- Современный интерфейс на PySide6

### Планируется

- Выбор папки сохранения EPUB
- Конвертация FB2 → EPUB
- Индикатор прогресса
- Сохранение настроек пользователя
- Сборка в портативный EXE
